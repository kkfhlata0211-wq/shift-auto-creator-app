# シフト自動作成アプリ

医療・介護現場などの月間シフト作成を支援する、ブラウザー上で動作するアプリです。スタッフや勤務区分を登録し、シフト案の自動作成、手動調整、制約チェックを行えます。

> 自動作成結果はシフト案です。すべての条件を満たすことや、法令への適合を保証するものではありません。運用前に勤務表と制約チェック結果を確認してください。

## 主な機能

- **月間シフト表**: スタッフごとの勤務区分、日別・月間の集計、必要人数を表示します。日付ヘッダーとスタッフ列はスクロール中も固定されます。
- **スタッフ管理**: 雇用形態、職種、夜勤可否、スキル、NGペアなどを設定できます。パートスタッフには1日の労働時間、週の勤務日数、勤務区分や曜日の固定設定があります。
- **勤務区分管理**: 勤務区分の表示名・略称・色・勤務時間などを編集でき、カスタム勤務区分の追加や並び替えもできます。
- **自動シフト作成**: ロック済みの割当や登録済みの希望、スタッフの勤務条件、必要人数などを考慮してシフト案を作成します。
- **手動調整**: シフト表のセルをクリックして勤務区分を変更できます。割当をロックすると、自動作成時にその割当を維持します。
- **行事・イベント**: シフト表の日付欄から行事やメモを登録できます。
- **リアルタイム制約チェック**: 連勤、夜勤連動、週の勤務日数・労働時間、必要人数、NGペアなどの確認結果を表示します。
- **月間所定労働時間**: 正社員の月間目標時間を設定し、実績との差を確認できます。

## はじめかた

### 必要なもの

- Node.js と npm
- デスクトップ向けの最新ブラウザー

### 開発サーバーの起動

```bash
npm install
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173/`）をブラウザーで開きます。ポートが使用中の場合は、別のポートが表示されることがあります。

### ビルド・プレビュー

```bash
npm run build
npm run preview
```

`npm run build` はTypeScriptのチェック後、本番用ファイルを `dist/` に生成します。`npm run preview` はビルド済みアプリをローカルで確認するためのコマンドです。

## 基本的な使い方

1. **スタッフ管理**でスタッフ情報、雇用形態、担当可能な勤務区分、固定条件などを設定します。
2. **条件・ルール**で連勤上限、勤務間隔、夜勤連動ルール、必要人数を確認します。必要に応じてカスタム勤務区分も登録します。
3. ヘッダーで対象年月と正社員の月間所定労働時間を設定します。
4. **自動作成**を実行し、生成後はシフト表と画面下部の制約チェックを確認します。
5. 必要に応じてセルを手動編集し、変更を維持したい割当をロックします。
6. 「保存」でJSONバックアップを作成するか、「CSV出力」で表計算ソフト向けの一覧を出力します。

## 保存とデータの取り扱い

- シフトプランはブラウザー内のSQLiteデータベース（sql.js）に保存され、IndexedDBを通じて次回起動時にも読み込まれます。データはブラウザーのプロファイルごとに保存され、別の端末やブラウザーとは自動同期されません。
- 既存のLocalStorageに旧形式のデータがある場合、起動時に移行を試みます。
- **保存**はプラン全体をJSONファイルに書き出します。File System Access API対応ブラウザーでは、初回に選んだファイルへ同じページを開いている間は上書き保存できます。「保存先を変更」から別のファイルを選択できます。ページを再読み込みした後は、保存先を再選択してください。非対応ブラウザーでは通常のファイルダウンロードを使用します。
- **データ読み込み**ではJSONファイルを読み込みます。既存の同じ年月のプランがある場合は、その年月のデータが読み込んだ内容に置き換わります。
- **CSV出力**はUTF-8 BOM付きです。列はスタッフ名、職種、雇用形態、日別勤務区分、月合計時間です。スタッフの行順はシフト表と同じです。
- ブラウザーのサイトデータを消去すると、IndexedDB内のプランも削除される場合があります。必要に応じてJSONバックアップを別の場所に保管してください。

## 自動作成・制約チェックについて

- 自動作成は段階的に候補を選ぶ方式で、すべての制約を同時に満たす最適解を保証しません。スタッフ数や固定条件によっては、必要人数に届かない場合があります。
- 夜勤連動ルール、夜勤可否、連勤上限、勤務間隔、NGペア、担当可能な勤務区分などを候補選定で考慮します。パートは設定された週勤務日数（複数設定時は最大日数を基準）や1日の労働時間を使って割当を調整します。
- カスタム勤務区分は、勤務扱いで夜勤専用ではなく、必要人数が設定されている場合に自動作成の対象になります。
- 自動作成で条件を満たせない場合があります。生成後に不足や違反が表示されたら、割当を手動調整して再確認してください。
- 現在の自動作成では、夜勤は1日あたり最大1名まで割り当てます。夜勤の必要人数をそれ以上に設定した場合も、追加の夜勤枠が生成されないことがあります。
