# 医療・介護向け PC専用シフト自動作成Webアプリケーション

医療および介護現場の複雑な労務制約（変形労働時間制、連続勤務制限、夜勤翌日ルール、NGペア同席回避、FTE・必要人数充足）を満たしながら、1ヶ月分のシフト表を自動生成・リアルタイム検証・微調整できるPC専用Webアプリケーションです。

## 主な機能
- **1ヶ月マトリクス表示**: PCのワイド画面に最適化した横軸（日付・行事）・縦軸（スタッフ）の固定スクロールUI。
- **シフト自動生成エンジン**:
  - 希望休（公休・有休・冠婚葬祭）の優先反映（Hard制約）。
  - 夜勤回数・土日祝出勤のスコアリングによる平準化。
  - NGペア（同一シフト同席禁止）の自動回避。
  - 連勤上限（4連勤まで）および勤務間インターバルの考慮。
- **リアルタイム制約検証（バリデーション）**:
  - 法定・契約労働時間オーバー警告。
  - 連勤オーバー・夜勤翌日ルール違反のセルハイライト。
  - 時間帯・シフト別必要人数の不足判定（画面下部フッターの赤色ハイライト）。
- **手動微調整・確定ロック**:
  - マトリクスセルをクリックして勤務区分を即時変更。
  - ピン留め（確定ロック）したセルは自動生成時も維持。
- **データ永続化 & ファイル入出力**:
  - LocalStorageへの自動保存。
  - JSON形式での設定・シフトバックアップ・復元。
  - Excelで開けるShift-JIS / UTF-8 BOM付きCSV形式エクスポート。

## 技術スタック
- **フロントエンド**: React 18, TypeScript, Tailwind CSS, Vite
- **アイコン**: Lucide React
- **ビルドツール**: Vite, TypeScript (Strict Mode)

## 開発・起動手順
```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build
```
